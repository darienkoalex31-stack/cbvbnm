# La base: i libri di Alex Hormozi

Questa cartella è il riferimento per ogni decisione di marketing, offerta, prezzo e pubblicità di Il Dono delle Note.

## La regola
1. **Alla domanda «come si fa?» si risponde dai libri**, citando libro e capitolo. Niente ricerche online, niente invenzioni.
2. **Se i libri non ne parlano, si dice chiaramente.** Per esempio: i pulsanti di Meta, Stripe o Netlify, le leggi italiane, il fisco.
3. **Le aggiunte non scritte nei libri si segnano sempre con ✏️.** Quello che viene dal libro si segna con 📖.
4. **Quello che manca nelle trascrizioni non si inventa:** immagini, tabelle, i 3 script di esempio e i template di landing page di $100M Leads.
